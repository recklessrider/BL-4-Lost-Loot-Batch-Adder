Lost Loot Batch Injector for Borderlands 4 based on the code provided by https://github.com/iyre/bl4-save-tools

Allows user to load a text file of a list of weapon serial codes to add to the lost loot machine for the save the user selects. 
Will create a backup of the savefile before execution and drop it next to the orginal file before modification.
